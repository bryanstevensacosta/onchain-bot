# Check Project Calls

This is a great way to find out:

1. How certain KOLs are performing
2. KOLs that called big projects early&#x20;
3. How much exposure (KOL wise) a project has had

To do this, simply head to the bot, type `/start` and select 'View project calls'.

After providing the CA, users will be shown a list (chronological in order of earliest, to latest to call the project) of KOLs, with links to their call, and relative Xs they have achieved.
