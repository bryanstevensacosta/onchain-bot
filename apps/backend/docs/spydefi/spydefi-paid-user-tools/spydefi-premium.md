# SpyDefi Premium

Unlike 'SpyDefi Live' there is more insights available per alert, with the chart displayed and also the KOL's consistency %&#x20;

It is also split into two channels, one for EVM, and a separate one for Solana.

Users of SpyDefi Premium, however, cannot adjust which projects, or KOLs, that appear.

{% hint style="info" %}
It is also worth noting that it is a curated list simply of KOLs that are above the average overall consistency % of all SpyDefi KOLs.
{% endhint %}
