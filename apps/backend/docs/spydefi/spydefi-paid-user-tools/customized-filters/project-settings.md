# Project Settings

In the project settings section, users can adjust which projects are eligible to appear on their feed through the following parameters:&#x20;

#### 📊 Marketcap

Set a minimum/maximum marketcap of projects you wish to appear in your feed.&#x20;

#### ⌛️Pair Age

Set a minimum/maximum pair age of projects you wish to appear in your feed.&#x20;

#### 🔗 Chains

Set the chain(s) of calls you wish to appear in your feed.

#### 📞 Total Calls

Set a total number of calls that a project is allowed to have received to appear in your feed.

#### 👆 See Project Once

Toggle this on so you can only receive one alert per project, to avoid alerts when other KOLs call it after you've seen it once.
