═══════════════════════════════════════════════════════════════════════
DI BUGS FOUND + FIXED VIA LIVE SMOKE TEST
═══════════════════════════════════════════════════════════════════════

1. Missing @Injectable() on StartCommandHandler + HelpCommandHandler
   → Without @Injectable(), Nest cannot read paramtypes metadata, passes undefined
   → Symptom: "Cannot read properties of undefined (reading 'sendMessage')"
   → Fix: Add @Injectable() decorator to both classes

2. TokenScanPipeline missing from module providers
   → XTokenScanHandler depends on TokenScanPipeline but pipeline wasn't registered
   → Symptom: "UnknownDependenciesException ... XTokenScanHandler at index [6]"
   → Fix: Add TokenScanPipeline to providers array in chain-dexter-bot.module.ts

3. command-router.service.ts had stale constructor (only registered /start, /help)
   → Wave 4 changes didn't propagate because file already existed
   → Symptom: All other commands (/x, /z, /c, /tb, /settings) hit "unknown command" path
   → Fix: Rewrite command-router.service.ts with full constructor + register all handlers

4. ChatGroupEntity + ChatSettingsEntity missing from PERSISTED_ENTITIES
   → TypeORM "No metadata for ChatGroupEntity was found" on first webhook
   → Fix: Add both entities to PERSISTED_ENTITIES array in database.module.ts
