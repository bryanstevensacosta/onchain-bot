## Getting Rick to work

1. **[Invite Rick](https://discord.com/application-directory/1081815963990761542)** to your server.
2. **Set Rick's highest role color to `#B0F646`**. This is required for Rick to respond correctly. Without this color, he won't activate.
3. **Grant the required permissions** in the channels you want Rick to operate in (see [in-depth setup](https://talk.markets/t/setting-up-rick-in-discord/1075)).
4. Follow [@rickburpbotnews](https://t.me/rickburpbotnews) on Telegram for updates.

## Highlighted commands

> **New:** `/groupath` — group leaderboards by ATH & stats for your community.

| Command | Purpose |
|---|---|
| `/groupath` | Community ATH leaderboard |
| `.x <token-or-ca>` | Token info (default; full contract + enhanced security) |
| `.z <token>` | Short token info (trimmed contract, limited security info) |
| `.twit <handle>` | Check Twitter handle for recycles |
| `.dp <ca>` | Check if DEX is paid (Solana tokens) |
| `/remind` | Quick reminders in your server |
| `.web <url>` | Find similar websites |
| `.d` / `.dx` | Channel summary (`.dx` = BETA improved) |
| `.s <url>` | TLDR anything (tweets, articles, YouTube) |
| `/index` | Top 10 coins by mcap |
| `/fixtwitter` | Toggle FxTwitter embeds on/off |

> **Prefix note:** Many Discord commands use a dot `.` prefix. If no prefix is shown in the docs, the command is a slash-command.

Full reference: [04-commands-discord.md](./04-commands-discord.md)

## What is Rick on Discord?

A multi-feature AI/crypto bot for community servers. Key features:

- Token scans for Solana, Ethereum, Base, BSC
- Token tracking + community leaderboards (`/groupath`)
- AI chat (DeepSeek, web-search, summaries, AI vision on Telegram only)
- Twitter/𝕏 previews via FxTwitter
- Dex paid checker, notable holders
- Custom trade buttons
- Chat summaries and TLDRs
- Reposts + new 𝕏 reposter for cleaner embeds
- Status monitor / ping checks
