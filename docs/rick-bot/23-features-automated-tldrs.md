# Feature — Automated Chat TLDRs

> **Resumen (ES):** Recapitulaciones automáticas de chats cuando están idle 15+ minutos. Solo para grupos Premium. Cada resumen cubre ~50 mensajes. Configurable con `/autotldr`. Fuente: [talk.markets/t/automated-chat-tldrs/8556](https://talk.markets/t/automated-chat-tldrs/8556).

---

## What are Automated Chat TLDRs?

**[Premium](https://talk.markets/t/learn-about-rick-premium/1021)** chats receive **automated recaps** of recent discussion, giving you **instant insights** on the **recent** discussion.

Key properties:

- TLDRs only fire when the chat is **idle for 15 minutes** — never mid-conversation
- Each summary covers approximately **50 messages** — tidy and relevant
- Catch up fast after stepping away
- See the real takeaways, not the noise
- Keep busy chats readable for everyone

---

## Usage

| Command | Action |
|---|---|
| `/autotldr on/off` | Toggle on or off |
| `/autotldr 5-60` | Set idle trigger time (5–60 minutes) |
