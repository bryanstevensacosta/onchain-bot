## Key concepts cheat sheet

### Identities

- **Telegram bot:** `@rick` or `@RickBurpBot` (any other handle is a scam).
- **Discord bot:** invite from Discord App Directory.
- **News channel:** [@RickBurpBotNews](https://t.me/RickBurpBotNews)
- **Global leaderboard:** [@BurpBoard](https://t.me/BurpBoard)
- **Web app:** [app.rick.bot](https://app.rick.bot)
- **X/Twitter:** [@RickBurpBot](https://x.com/RickBurpBot)
- **Developer:** [@Lux](https://talk.markets/u/Lux) / [@MentionLux](https://twitter.com/MentionLux)

### Two credit systems

- **AI credits** — for AI commands (`/ask`, `/deep`, summaries, image gen). Buy with Telegram Stars via `/topup`.
- **Burps** — fun-money for Blackjack and games. 25,000 free every 24h via `/bank`. **No real-world value.**

### Chains supported

Solana (default), Ethereum, Base, BSC, TON, Fantom, Avalanche. More on request.

### Required for token tracking

- Telegram chat must be a **supergroup** for groupburp, groupath, etc.
- Discord: Rick's highest role color must be **`#B0F646`**.

### Scam warning

**There is NO token for Rick. There are no plans to launch one.** Any Rick-related token or "airdrop" is a scam.
