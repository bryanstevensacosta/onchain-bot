## 2026

### January 2026 — PVP Token Finder

- New feature to quickly see **relevant tokens of interest** matching a ticker
- Auto-shows on tokens younger than 24h
- Manual: `/pvp <symbol or address>` or `/pvp` in reply

### February 2026 — Rick Hub (Full release)

- **Rick Hub** is now the unified feed app at [app.rick.bot](https://app.rick.bot)
- Aggregated scans from Telegram + Discord in one real-time view
- BETA status with continuous improvements
- [More info](./10-features-hub.md)

### March 2026 — News Command & AI updates

- `/news` improvements
- AI QOL updates
- Macro Snapshot released

### April 2026

#### 📟 Rick Hub [BETA] announcement

- **All groups in ONE real-time feed**
- Discord + Telegram
- Telegram **Mini App** support
- Filters, Android/iOS push notifications
- Hide any group or user
- New & unique insights per group / token / user
- Combined search through all your groups
- [Source](https://talk.markets/t/introducing-rick-hub-beta/8390)

#### Deleted Tweets & Stock Lookup

- Rick now monitors shared tweets for deletion
- New `/xd` for last 5 deleted tweets for an X account
- New `/tweetdels on/off` to toggle alerts
- New `/s` command for stocks, commodities, and traditional instruments
- [Source](https://talk.markets/t/deleted-tweets-stock-lookup/8417)

#### Multi-chain OG Finder

- `/old <symbol>` / `/old <address>` — find oldest tokens by ticker across chains
- `/new` — newest first
- Suffixes: `vol`, `<network>`, `fuzzy`, `mc`
- [More info](./19-features-og-finder.md)

#### Multi-chain PVP revamp

- The **PVP command** is now multi-chain
- Auto-show on scans remains same-chain
- [More info](./20-features-pvp-finder.md)

#### Instant CTO alerts

- Premium Telegram chats receive **instant CTO alerts** by default
- Sourced from [DexScreener](https://marketplace.dexscreener.com/product/token-community-takeover)
- Max 2 pings/minute to avoid spam
- [More info](./22-features-alerts.md#instant-cto-alerts)

#### Blackjack (for fun)

- A often-requested fun feature
- Burps currency (no real value)
- Daily 25k burps via `/bank`
- Side bet: Perfect Pairs
- Progressive jackpot (3% of every wager)
- [More info](./17-features-blackjack.md)

#### Polymarket improvements

- Share a Polymarket link → Rick posts details
- `/pm` to search Polymarket
- `/metas` for trending narratives
- `BBW` (Based Bot Web) added to `/tb`
- `/tweetdels off` to disable deleted tweet alerts

### May 2026

#### CoinCommunities

- New `/com` and `/comms` to instantly grasp any community
- Top KOLs and top posts
- Community links added to `/soc` (`.soc` on Discord)
- [Source](https://talk.markets/t/coincommunities-are-live-on-rick/8542)

#### Query Deleted Tweets + Alerts

- `/xd <username>` — last 5 deleted tweets for an X account
- `/tweetdels on/off` — toggle deletion alerts
- Deeplinks via :wastebasket: emoji on reposts
- Alerts only fire in supergroups and only for shares < 7 days old
- [Source](https://talk.markets/t/query-deleted-tweets-alerts/8511)

### June 2026

#### Automated chat TLDRs

- **Premium** feature
- Fires when chat is idle for 15+ minutes
- Covers ~50 messages
- `/autotldr on/off` or `/autotldr 5-60` to configure
- [Source](https://talk.markets/t/automated-chat-tldrs/8556)

#### World Cup alerts & Polymarket odds

- `/sports on/off` — opt in for live World Cup score alerts
- Alerts: kickoff, goals, score changes, half-time, full-time
- Includes score, odds, and Polymarket button
- Admin-only setting, supergroups only
- [Source](https://talk.markets/t/world-cup-alerts-polymarket-odds/8577)
