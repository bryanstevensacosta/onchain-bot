# Rick Premium

> **Resumen (ES):** Suscripción premium que desbloquea alertas consistentes, TLDRs automáticos, contexto 2× para resúmenes, alertas garantizadas de DexPaid, CTO instantáneo y créditos AI gratuitos. ## What is Premium?

**Rick Premium** is a subscription tier that enhances the bot with always-on alerts, AI capabilities, and higher limits. It is a **separate concept from the AI credit system** — both can be active.

---

## What you get

- **Consistent `#UPDATE` alerts** for scanned tokens in your group ([details](https://talk.markets/t/active-token-tracking-for-communities/1326#p-6557-price-alerts-4))
- **[Automated chat TLDR's](./23-features-automated-tldrs.md)** — recaps of recent discussion when chat is idle
- **2× message context** for [chat summaries](https://talk.markets/t/chat-summaries/3443)
- **Guaranteed [DexPaid Alerts](./22-features-alerts.md#dexpaid-alerts)**
- **[Instant CTO alerts](./22-features-alerts.md#instant-cto-alerts)** — sourced in realtime from DexScreener
- **Request free¹ [AI credits](https://talk.markets/t/credits-for-rick/1136)**

> ¹ *Fair usage applies.*

---

## AI Credits (related but separate)

Some AI commands use a credit system to prevent abuse. Every group and user gets some **free credits** to try out AI commands.

- Read the full credits doc: [Credits for Rick](https://talk.markets/t/credits-for-rick/1136)
- Commands like `/ask`, `/deep`, `/grok`, `/dubs`, AI image generation, and other AI features consume credits.
- Premium groups can request free credits (fair-use).

## How to subscribe

### On Telegram (recommended)

In any group, run:

```
/premium
```

This opens the in-app payment flow using **Telegram Stars**. See [Telegram Stars: pay for digital goods](https://talk.markets/t/telegram-stars-pay-for-digital-goods-and-more/2660).

### Via form (whitelist / direct subscription)

If you need to be whitelisted or want a direct subscription, fill the form:

**[tally.so/r/mB7bqA](https://tally.so/r/mB7bqA)**

---

## Pricing

Pricing is set dynamically via Telegram Stars and may vary by region / group size. Run `/premium` in a Telegram group to see the current price for that group.
