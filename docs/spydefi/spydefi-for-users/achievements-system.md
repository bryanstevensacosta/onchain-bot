# Achievements System

KOLs are awarded a vast range of accolades, based on factors such as: individual Xs for a specific call, notable recent performance, being the first call on a notable project and much more.

Whilst some of the achievement posts are merely counting the specific X for the call, many are named with various themes and space specific terminology.&#x20;

This provides users with a chance to monitor the feed, identifying not only which projects are getting a lot of attention but also identify channels obtaining notable accolades.
