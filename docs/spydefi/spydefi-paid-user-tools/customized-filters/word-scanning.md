# Word Scanning

This novel tool allows users to tap into the thoughts, and insights, of thousands of KOLs and also capitalise on current trends and metas in the space.&#x20;

#### ✍️ KOL Mention

Users can select from a bank of provided words/phrases or even provide custom ones, and receive call alerts when a KOL's post includes them. Users can have up to 10 words being scanned for at once, with the ability to toggle on whether 'all' or just 'one' need to be present in the post, to trigger an alert in their feed.&#x20;

#### 📊 Project Name

Users can use this to find projects posted that have a certain word or phrase in the project name. For example, if the current meta was *Pepe* themed coins, users could input that word for the bot to scan for, and any project called, which includes the string of characters *Pepe*, that also meets the rest of your filter criteria, would trigger an alert.&#x20;

#### 🔄 Either

This will mean that any toggled on key word(s) can appear either in the token name OR the call post itself, this is a way of upping the odds of the word being triggered if desired.
