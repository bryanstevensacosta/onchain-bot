# SpyDefi Preset Filters

Current the following preset filters are on offer.&#x20;

#### 🔥 NEW LAUNCHES   &#x20;

*This filter is for catching new launches across different chains*

#### ⚒️ UTILITES

*This filter utilizes a minimum consistency score in combination with the 'word scanning' tool in an attempt to identify calls for* *utility projects.*

#### 🟣 SOL

*This filter is a 'catch-all' preset for SOL projects posted by KOLs with an average + consistency %*

#### 🟡  BSC

*This filter is a 'catch-all' preset for BSC projects posted by KOLs with an average + consistency %*

#### 🔷 **ETH**

*This filter is a 'catch-all' preset for ETH projects posted by KOLs with an average + consistency %*

#### 🤫 IN THE KNOW

*This filter utilizes a minimum consistency score in combination with the 'word scanning' tool in an attempt to identify calls where the KOLs have given their thesis or shared knowledge.*&#x20;

#### ⚡️ SPYDEFI APEX

*SpyDefi Apex is a algorithmically powered preset, informed by our data to provide call alerts from the highest performing KOLs of recent.*

{% hint style="info" %}
Confused on the 'Word Scanning' feature? Read more about it in the 'Customized Filters' section.
{% endhint %}
