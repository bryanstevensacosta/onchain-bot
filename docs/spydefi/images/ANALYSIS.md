## Key Visual Themes

### Recurring UI Patterns
- **SpyDefi logo lockup:** All section banners use the same hooded-spy mascot logo (fedora + glowing sunglasses) on the left, with a glowing neon outline headline on the right. This is the dominant visual identity for ~24 of the 28 images.
- **Background palette:** Two primary banner backgrounds — a green-aurora/space scene with stars and a darker green digital-network/circuit scene. A handful use a green-neon-lit wall (achievements, project calls) and one uses a green swirl (KOL bot, notify, calls-of-the-week).
- **Section header banners:** Most pages lead with a single banner image whose only job is to brand the section (e.g., "TRENDING", "BUY BOT", "KOL CLUB", "SPYDEFI STATS"). Roughly 22 images are pure banners.
- **Telegram bot screenshot format:** Five or six images are actual Telegram-message screenshots, all following the same block format — bot header → notification line with KOL handle + ticker + marketcap + pair age → CA → consistency/total-calls metrics → inline buttons (`View Call`, `View Stats`, sometimes `Join Channel`).

### Telegram Card Content Patterns
- **Call alert cards (Live / Premium):** "X just posted TICKER at $YM marketcap" with pair age, full CA, caller consistency %, and total-calls-for-project count.
- **Pro filter alert card:** Adds Dexscreener-style aggregated stats (Avg Mcap, Avg Score, Overall / Chain / Recent Consistency).
- **KOL achievement card (Kol Club):** Big visual header (banner graphic with ticker, multiplier, entry/ATH) followed by a bullseye-emoji callout and an icon-led metric list (Caller, Called At, ATH, Multiplier).
- **SpyDefi Moment card:** Includes an attached image (often the project/logo), a `SPYDEFI MOMENT` label, KOL handle, "Best X" multiplier, Recent Consistency %, a one-line italic bio describing the KOL, and `Join Channel` / `View Stats` buttons.
- **Verify confirmation card:** Minimal — single line stating "@owner is the verified owner of @channel ✅".
- **Leaderboard graphic (Calls of the Week):** A standalone designed image (not a Telegram screenshot) with the SpyDefi logo, 5 numbered ranked rows, each row containing rank, KOL handle, ticker tag with chain icon, multiplier number, and a thumbnail for the project, with `@SPYDEFI` footer.

### Achievement / Badge Graphics
- **`x2.png`:** A pixelated neon-orange "X2" badge on a dark circuit background — represents a multiplier achievement tier.

### Third-Party Asset
- **Maestro banner:** Sole non-SpyDefi-branded graphic, promoting Maestro as an integrated auto-trader, with chain-logo row.
