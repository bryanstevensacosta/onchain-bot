# How to list a channel

You simply need to go to [t.me/spydefi\_bot](https://t.me/spydefi_bot), type `/start` and select '*Track My Channel*'.

Here you are presented with two options, *'Join The Queue*' or '*Fast Track*'.

{% hint style="info" %}
It is worth noting that such is the space wide adoption of SpyDefi that there is an extremely long queue time due to the high level of demand from KOLs.
{% endhint %}
