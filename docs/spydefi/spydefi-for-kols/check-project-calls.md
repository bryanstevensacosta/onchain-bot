# Check Project Calls

KOLs are able to see how early they were to call a project relative to their peers, via the main SpyDefi bot ( [t.me/spydefi\_bot](https://t.me/spydefi_bot) )

Head to the bot, type `/start` and select 'View project calls'.

After providing the CA, users will be shown a list (chronological in order of earliest, to latest to call the project) of KOLs, with links to their call, and relative Xs they have achieved.
