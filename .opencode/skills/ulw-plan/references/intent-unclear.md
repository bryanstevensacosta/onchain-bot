# ulw-plan — UNCLEAR intent (local V2 adaptation)

UNCLEAR = outcome itself fuzzy (vague brief, bootstrap, no selectable plan).
Adapted from OMO (Metis/Momus → `oracle`). See `../NOTICE.md`.

## Stance

Do NOT interrogate. Resolve by RESEARCH; ANNOUNCE loud best-practice
defaults. User time only for an irreversible/destructive/safety-critical
fork research cannot settle — then exactly one focused question. Veto
happens at the gate via the TL;DR, not via interview.

## Research protocol

WIDER fan-out than CLEAR: more parallel lanes, more waves, until clearance
is answerable. Architecture-scale → collect → verify → design →
adversarial → synthesize (`full-workflow.md`); external = claims;
dirty-worktree aware; misleading success rejected. Every claim traces to a
subagent result or direct read; outputs are claims until verified.

Topology lock still applies — as ANNOUNCEMENT: 1–6 components in the draft
ledger; every todo traces to one; never collapse a vague request to one.

## Defaults

Per open decision: adopt defensible default (standard or repo convention),
RECORD in Open-assumptions ledger (rationale + reversibility), proceed. No
numeric scoring — the ledger is the audit trail. Escalate to one question
ONLY an irreversible/destructive/safety-critical fork research can't settle.
Fold a contrarian self-grill into the oracle spawn (highest-leverage
assumption: real constraint or habit? simplest version that delivers?);
reframes enter only as recommended defaults + rationale.

## Auto review

Adversarial review SUBSTITUTES the skipped interview. After writing: oracle
gap pass (always) + oracle review loop AUTOMATICALLY — fix cited issues,
resubmit fresh until APPROVE. TRIVIAL guard: vague-but-tiny → oracle gap
once, no review loop.

## Approval gate

Brief + wait for okay (approval ≠ execution), but brief LEADS with approach

- adopted defaults, surfacing "Decisions I made for you" in the TL;DR for
  veto. Lead with the routing call ("treated as open-ended; say so to switch
  to asking") so a mis-route is a one-line correction. Draft (Components +
  assumptions + gate) is the resume point. `/start-work` bootstrap exception:
  "start work" counts as approval to generate AND begin.

## Worked example

"Make auth better": research → current state + baselines; components
ANNOUNCED (session hardening, brute-force, password policy, MFA deferred);
defaults table (assumption|default|rationale|reversible); auto review →
brief leading with approach + defaults for veto.
